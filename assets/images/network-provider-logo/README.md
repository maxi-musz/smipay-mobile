# Network Provider Logos

Add PNG logo files for airtime network selection:

| File | Provider |
|------|----------|
| `mtn-logo.png` | MTN |
| `glo-logo.png` | GLO |
| `airtel-logo.png` | Airtel |
| `9mobile-logo.png` | 9mobile (Etisalat) |

Recommended size: 200×200px or similar square aspect ratio.

Convert SVG to PNG if needed (e.g. `airtel-logo.svg` → `airtel-logo.png`).
